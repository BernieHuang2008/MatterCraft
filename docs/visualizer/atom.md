# Visualize Atom

## 定位

`visualize atom` 是 `visualizer` 模块中最基础、也最完整的一个 visualizer。  
它接收 `AtomLogic` 对象，并将其转换为适合教学展示、结构理解与后续科学扩展的原子可视化场景。

`visualize atom` 是一个独立于 `matter_core` 的展示层模块：

- 输入为 `AtomLogic`
- 输出为可渲染的可视化场景数据与信息面板数据
- 不直接修改 `AtomLogic` 本身

## 设计目标

`visualize atom` 的第一目标不是构建高度复杂的 3D 炫技场景，而是让用户能够快速看懂一个原子的结构信息。

因此第一版采用两种模式：

- `teaching`：偏 2D 的教学模式，强调一眼看懂
- `structural`：偏结构与分布展示的模式，允许显示更深入的轨道与概率密度信息

这里明确不再保留单独的 `physical_strict` 模式。  
未来更科学的波函数与概率密度展示，统一并入 `structural` 模式演进。

## 理论口径

`visualize atom` 第一版展示的是教学与结构理解友好的量子近似表示，不是电子经典运动轨道的真实录像。

这句话应作为文档和 UI 文案中的固定口径。

更具体地说：

- 电子排布式采用标准化学教学表示
- 轨道表示式采用标准方框图与自旋箭头表示
- 电子云图主要表示轨道概率分布的教学近似
- 第一版不宣称展示严格多电子体系真实波函数

## 输入

输入对象：

```python
AtomLogic
```

最低必需字段：

```text
bAtomicNumber
bMassNumber
bCharge
bElectronConfig
```

可直接复用的自动属性：

```text
aProtonCount
aNeutronCount
aElectronCount
aValenceElectronCount
```

## 输出

建议 `visualize atom` 统一输出两部分：

1. `scene`
2. `panel`

其中：

- `scene` 表示场景节点、布局、选中态、高亮态与显示模式
- `panel` 表示电子排布式、轨道表示式、解释文本与对象摘要

建议不要让 renderer 直接读取 `AtomLogic`，而是统一消费 visualizer 产出的中间表示。

## 模式定义

### `teaching` 模式

`teaching` 模式采用偏 2D 的展示效果，目标是让用户一眼看懂这个原子当前的结构。

推荐显示内容：

- 黑色或近黑色背景
- 中心简化原子核图形
- 原子核标签，例如 `+7`
- 简写电子排布式，例如 `[He] 2s² 2p³`
- 元素符号、原子序数、质量数、电荷、电子总数
- 被点击 subshell 的轨道表示式

推荐视觉风格：

- 场景整体平面化或弱透视
- 电子排布式与轨道框图优先保证可读性
- 不依赖复杂的 3D 摄像机绕行
- 用户进入时无需理解空间旋转即可读懂信息

### `structural` 模式

`structural` 模式用于展示更深入的结构信息，允许引入更强的空间感，并支持轨道概率分布的展示。

推荐显示内容：

- 原子核
- 简写排布式与展开排布树
- 轨道表示式
- 被选轨道的电子云图
- 轨道类型说明
- 当前选中对象的结构解释

`structural` 模式仍然属于展示层近似模型，但比 `teaching` 模式更接近“结构观察”。

## 默认首屏

默认进入 `teaching` 模式。

默认首屏建议只显示：

- 原子核
- 核电荷数
- 简写电子排布式
- 原子基础摘要

例如氮原子：

```text
+7
[He] 2s² 2p³
```

这里需要注意：

- 核电荷数由原子序数决定
- 离子化改变电子数，不改变核电荷数

## 电子排布式显示规则

默认采用原子实简写：

```text
[He] 2s² 2p³
```

规则：

1. 首屏优先显示价层相关部分。
2. 已知惰性气体内核优先折叠为原子实。
3. 原子实是可点击对象，不是纯文本。
4. 展开时采用逐层递归展开，而不是一次性完全展开。

例如：

```text
[Ar] 4s²
```

点击 `[Ar]` 后：

```text
[Ne] 3s² 3p⁶ | 4s²
```

继续点击 `[Ne]` 后再展开其内部内容。

## 交互状态机

建议 `visualize atom` 维护以下状态：

- `overview`
- `core_expanded`
- `subshell_selected`
- `orbital_selected`
- `electron_selected`

状态含义：

- `overview`：默认视图，只看简要结构
- `core_expanded`：原子实已展开
- `subshell_selected`：选中了某个 subshell，例如 `2p³`
- `orbital_selected`：选中了某个具体轨道框
- `electron_selected`：选中了某个具体自旋箭头

## 点击行为

建议行为如下：

1. 点击原子实：展开或折叠其内部电子排布。
2. 点击 subshell：显示对应轨道表示式。
3. 点击轨道框：高亮该轨道，并切换到其电子云展示。
4. 点击箭头：显示该电子占据解释与自旋说明。
5. 点击空白区域：清除当前局部选择或返回上一级。

## 轨道表示式

轨道表示式采用标准教学方框图。

基本规则：

- `s` 轨道对应 1 个框
- `p` 轨道对应 3 个框
- `d` 轨道对应 5 个框
- `f` 轨道对应 7 个框

箭头规则：

- 向上箭头与向下箭头表示相反自旋
- 同一个框内最多两个电子
- 排布应遵循当前 `bElectronConfig`

例如：

```text
1s²: [↑↓]
2s²: [↑↓]
2p³: [↑] [↑] [↑]
```

这里的显示解释应明确说明：

- 框表示轨道
- 箭头表示电子占据
- 该表示法不等于电子经典轨迹

## 电子云显示

第一版电子云显示建议优先支持：

- `s`
- `p`

后续扩展：

- `d`
- `f`

显示原则：

- `s` 轨道使用近球形概率云
- `p` 轨道使用双瓣概率云
- 同一轨道中不同自旋电子共享同一空间云图
- 自旋差异通过说明文字和高亮表现，不通过改变云图形状表现

推荐显示方式：

- 半透明体积云
- 等值面
- 亮度或透明度切换

## 原子核显示

原子核在第一版中主要承担两个职责：

1. 提供视觉中心
2. 提供核信息入口

推荐展示内容：

- 发光球体或平面化核心圆点
- 核电荷数标签，例如 `+7`
- 可选显示质量数与中子数摘要

第一版不强制展示核内质子/中子的详细排布图。

## UI 建议

推荐采用“主画面 + 侧边信息面板”的结构。

主画面：

- 原子核
- 简写排布式
- 当前选中的电子云或轨道高亮

信息面板：

- 元素摘要
- 当前电子排布式
- 当前 subshell 的轨道表示式
- 理论解释

这样可以避免用户在复杂 3D 空间里迷失，同时保留向更深层结构展示扩展的能力。

## 与后续模块的关系

`visualize atom` 将作为整个 `visualizer` 模块的交互母版。

后续建议：

- `visualize molecule` 可点击 atom 下钻到 `visualize atom`
- `visualize matter` 可点击局部 molecule 下钻到 `visualize molecule`
- `visualize mixture` 可点击 component 下钻到 `visualize matter`

## 第一版建议范围

第一版建议做到：

- 输入 `AtomLogic`
- 默认 `teaching` 模式
- 黑底平面化或弱 3D 首屏
- 原子核与核电荷数
- 简写电子排布式
- 原子实展开
- `s/p` 轨道表示式
- `s/p` 电子云
- 统一解释文案
- `structural` 模式中的科学波函数 TODO 预留

第一版暂不要求：

- 严格多电子波函数数值求解
- 高精度时间演化
- 核内粒子动力学展示
- 全量 `d/f` 复杂视觉细节
