# Dev Note

## 目标

本目录用于保存 MatterCraft 的开发约定、代码概念、模块划分和实现规则。项目使用 Python + Pygame 开发，推荐使用 Python 3.12.10 进行编译和运行。

## 核心结构

MatterCraft 的核心结构分为三类模块：

- `descriptor`：对象的描述符，负责表达对象是什么、有哪些基础定义。
- `calculus`：计算过程中使用的高效数据结构，负责优化运行时计算和缓存。
- `logic`：对象在代码中被操作的相关部分，负责行为、流程和交互逻辑。

每个 class 都需要包含与这三类结构对应的模块或设计入口。三个类别会分别进行不同程度的优化，以保证项目运行良好。

## 开发原则

1. 文档优先：所有代码修改都必须先参考 `docs` 中的相关导航和说明。
2. 命名一致：类名、变量名、方法名遵守项目命名规范。
3. 类型明确：所有函数都需要添加类型注解。
4. 注释完整：每个函数和 class 都必须有注释，注明功能与参数信息。
5. 逻辑可追踪：所有实现逻辑必须以注释形式写在对应函数或 class 下方。
6. 调试统一：所有调试信息必须通过 Debug 模块输出，不直接使用零散打印。
